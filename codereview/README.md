# Code review findings

Здесь накапливаются замечания из ревью кода. На их основе составляется roadmap исправлений и техдолга.

## Как пользоваться

- Каждый сеанс ревью → файл `YYYY-MM-DD-<тема>.md` или дополнение к существующему
- Пункты: приоритет, где, что, почему, статус (`open` / `fixed`)
- Не удалять историю без необходимости — закрытые пункты помечаются `fixed`

## Приоритеты

| Метка | Смысл |
| --- | --- |
| `critical` | Блокер, баг, утечка, нарушение безопасности |
| `high` | Архитектура / контракт слоёв, регрессии |
| `medium` | Консистентность, DX, тесты |
| `low` | Стиль, мелкие улучшения |
